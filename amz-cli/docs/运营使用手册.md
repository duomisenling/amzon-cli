# 亚马逊运营助手 · 使用手册（给运营同事）

这份手册教你**怎么跟 AI 助手开口**，让它稳定地帮你查数据、做运营。不用懂技术，照着说就行。

---

## 一、开始之前

- 在 Cherry Studio 里打开配好 `amz-cli` 技能的那个助手/智能体，**新开一个会话**。
- 管理员会提供一个统一的多店铺 MCP JSON；同事只需在已安装同版本 `amz-cli` 的 Windows 电脑上导入，不需要自己生成五份配置。账号凭证由管理员放到本机指定目录，JSON 本身不包含密钥。
- 直接用大白话说你要干什么即可，例如「帮我看看店铺最近卖得怎么样」。
- 有多个店铺时，先记住管理员给你的店铺代号（如 `shop-a`、`shop-b`、`shop-c`、`shop-d`、`shop-e`），每个新任务都要让当前对话明确「查/改哪个店铺」。店铺代号不确定就先问管理员，助手不能替你猜，也不能自动使用默认店铺。
- 助手每次会**先只读查询**给你看结果；**改动类操作**（改价、改预算等）它只会先给你预览，最终执行要**你在弹出的审批卡上点允许**。

> 说话小技巧：**一句话里把关键信息给全**——哪个店铺/站点、哪个商品（ASIN 或 SKU）、什么时间范围。信息给全了，它一次就能查对，不用来回问。

---

## 二、查数据（只读，随便问）

下面左边是你想知道的，右边是**照着说**的示范。把示范里的占位符换成你的真实信息。

| 你想知道 | 照着说 |
|---|---|
| 全店最近卖了多少 | 「查一下 **shop-b 店铺美国站**最近 **7 天**的销售额和销量」 |
| 某个商品卖得怎样 | 「看看 ASIN **B0XXXXXXX** 最近 **30 天**的销量」 |
| 某个 SKU 的表现 | 「SKU **ABC-123** 最近 14 天卖了多少」 |
| 最近的订单 | 「列一下最近的订单」／「查订单号 **123-4567890** 的详情」 |
| FBA 还有多少库存 | 「查一下 FBA 库存」 |
| FBA 货件到货情况 | 「看看最近的 FBA 货件有没有收货差异」 |
| 我自己的 listing | 「列出我店铺**美国站**的 listing」／「查 SKU **ABC-123** 的 listing 详情」 |
| 竞品/BuyBox（任意商品） | 「查 ASIN **B0XXXXXXX** 的商品详情和 BuyBox」 |
| **我自己有没有丢 Buy Box** | 「看看我 **shop-b 美国站**这些 ASIN 有没有丢 Buy Box：**B0XXX, B0YYY…**」／「只列丢了的」 |
| **哪些 listing 被压制/搜不到** | 「查一下 **shop-b 美国站**有哪些 listing 被压制了、搜不到、有报错」 |
| 费用预估 | 「估算一下 ASIN **B0XXXXXXX** 的亚马逊费用」 |
| 广告账户/活动 | 「列出我的广告账户」／「列出广告活动」 |
| **哪些广告在烧钱/ACOS 高** | 「看看 **shop-d 美国站**最近 **30 天**哪些广告活动 ACOS 太高、有没有花了钱没出单的」 |
| 哪些搜索词白花钱 | 「找出 **shop-d 美国站**最近 **30 天**点击多但没成交的搜索词」 |
| 差评/卖家反馈 | 「拉一份店铺的卖家反馈报告」（注意：这是全店反馈，不能按单个 ASIN 过滤；期间没有差评会直接告诉你"没有"，不算出错） |
| **按站点时区看日销** | 「按**洛杉矶时区**查 shop-b 最近 7 天每天的销售额」（不说时区默认按 UTC 切天，和后台日报会有几小时口径差） |
| 网络出口自检（管理员让你查时） | 「跑一下出口自检，看看现在的出口 IP 是多少」 |

**关于站点/区域**：默认查的是账号的默认区域。查**欧洲站点**（英德法意西）时，明确带上国家，例如「查**德国站** DE 的…」。北美和欧洲是两套独立凭证，查不到对方是正常的。

同一段连续对话里已经明确了店铺时，后续只读追问可以继续使用该店铺，助手会在结果中再次写明店铺；新任务没说店铺、前面出现过多个店铺或目标有歧义时，助手必须先问你，不能猜。

## 三、做改动（改价、改预算等 —— 要审批）

这些属于**写操作**，助手不会直接改，而是走「**先预览 → 你审批 → 才执行**」。

**怎么开口：**

| 你想做 | 照着说 |
|---|---|
| 改 listing（标题/价格/图片等） | 「把 **shop-b** 的 SKU **ABC-123** 标题改成『…』」 |
| **新建一个 listing** | 「在 **shop-b 美国站**新建一个 listing，SKU **NEW-123**，产品类型 **XXX**，属性：…」（不确定要填哪些属性，先说「先查一下这个产品类型要填哪些字段」） |
| 改广告日预算 | 「把 **shop-d 美国站**广告活动 **XXXX** 的日预算改成 **20**」 |
| 启用/暂停广告 | 「暂停 **shop-c 德国站**广告活动 **XXXX**」 |
| 改关键词竞价 | 「把 **shop-a** 的关键词 **XXXX** 竞价改成 **0.8**」 |
| 加否定词 | 「给 **shop-e** 广告组 **XXXX** 加否定词『免费』」 |
| 从零建一套关键词广告 | 「在 **shop-b 德国站**用这些关键词给 ASIN **B0XXX** 建一套广告：…（词、预算、竞价）」 |
| **批量**暂停一堆烧钱广告 | 「把刚才查出来 ACOS 太高的这几个广告活动**都暂停**」 |
| **批量**改一堆竞价/预算 | 「把这几个关键词竞价**都降到 0.5**」／「把这几个活动日预算**都改成 15**」 |
| **批量**加一堆否定词 | 「把刚才查出来白花钱的这些搜索词**都加成否定词**」 |

> **批量改动**：助手会把整批「谁、从什么值→什么值」列成一张清单让你一次看完；**你审一次、审批卡点一次**，就整批执行。清单里已经是目标值/找不到的会自动跳过；**已归档**的活动/关键词会标"不可改"，不会白白执行。
>
> ⚠️ **批量执行后如果出现「结果不明」**（一般是执行途中网络断了）：助手会单独列出这些项并提醒你——**不要直接让它重跑**，先让它查一下当前值核对是否已经改成功，确认没改上的再重来。尤其是加否定词这类操作，盲目重跑可能加重复。

**执行流程（重要，务必照做）：**

1. 助手先给你一份**预览**：店铺、站点、改什么、从什么值变成什么值。前文已经明确店铺时，不会再单独多问一次，而是和本次改动一起确认。
2. **你核对**：店铺、站点、商品、金额、关键词对不对。
3. 对了，就等 Cherry **弹出审批卡**；多店铺 MCP 的工具参数中必须显示正确的 `account` 店铺代号。在卡上再次核对店铺后**点允许**——这一步才真正写进亚马逊。
4. 卡上的内容和预览**对不上就点拒绝**，让助手重新预览。

> ⚠️ 安全底线：聊天里打「确定/好/Y」**不算**批准，只有**审批卡上的点击**才算。金额、商品、站点和预览不一致，一律拒绝。

## 四、让它更听话的小技巧

- **信息一次给全**：ASIN/SKU、站点、时间范围、金额一起说，减少来回。
- **不满意就直接纠正**：「不对，我要的是**德国站**」「时间改成最近 **90 天**」——它会重来。
- **只要结论**：它默认会用中文总结金额、时间、异常项，不用你看原始数据。想看明细再说「把明细也列出来」。
- **一次只说一件事**：复杂需求拆开说，别把五六件事堆一句。

## 五、遇到"不太对劲"怎么办

| 现象 | 多半是什么 | 你可以怎么做 |
|---|---|---|
| 它说找不到 `amz-cli` | 没装好或没重装 | 让管理员重跑安装命令 |
| 改动类操作没弹审批卡 | 写工具（MCP）没挂上 | 找管理员确认 Cherry 里挂了 MCP |
| 查欧洲站点查不到 | 用的是北美默认区域 | 明确说「查德国站 DE」，或让管理员确认配了欧洲凭证 |
| 报"没有凭证/refresh token" | 这台电脑凭证没配好 | 找管理员配 `~/.amz-cli/.env` 并**重启 Cherry** |
| 它找不到店铺或审批卡店铺不对 | 店铺代号没说清、账号文件缺失，或 `account` 选错 | 不要批准；明确告诉助手正确店铺，仍失败就让管理员检查对应账号文件和多店铺 MCP 配置 |
| 改了凭证还是不生效 | 改完没重启 | 让管理员**重启 Cherry**（配置只在启动时读一次） |
| 它跑一堆没用的命令 | 助手在瞎试 | 把需求说得更具体；或让管理员升级到最新版 |
| 报告里看不到买家姓名/地址/电话 | 不是故障，是隐私保护 | 工具会自动删掉报告里的买家个人信息列，这是刻意设计，无法绕过 |
| 批量改动后有几项"结果不明" | 执行途中网络中断 | 别急着重跑：先让助手查当前值核对，确认没改上的再重来 |
| 提示"该 ASIN 对应 SKU 太多" | 一个 ASIN 下挂了很多 SKU | 直接改用 SKU 说：「改 SKU ABC-123 的…」 |

**任何看不懂的红色报错**，不用自己猜——**截图发给管理员**，里面通常写清了缺什么。

---

## 六、一句话记住

> 说清楚「**哪个店铺 · 哪个站点 · 哪个商品 · 什么时间 · 想干什么**」，查数据随便问，改动看预览、在**审批卡**上把关。
