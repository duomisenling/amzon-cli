# 已有广告优化

## 1. 读取本店真实数据

统一时间窗口，优先近30天；新品测试或近期调整可同时查看7天与30天。按最小调用获取：

- `ads coverage`、`product-ads`：ASIN/SKU到Campaign和广告组映射
- `ads performance`：Campaign或广告组表现
- `ads report-run --type targeting`：关键词/定向表现
- `ads report-run --type search-terms`：真实买家搜索词
- `ads campaigns/keywords`：当前状态、预算、竞价和名称
- `ads wasted-spend`：零转化候选，仅作候选入口，不直接等于应否定

账户级报表一次拉取后筛选批量ASIN，不为每个ASIN重复创建报告。

## 2. 计算目标与样本

读取 `calculations.md`。优先使用运营目标ACOS和商品利润边界。比较花费、销售额、订单、点击、ACOS、CPA、CPC、CTR和CVR；零订单按统计点击门槛判断，不因少量点击过早暂停。

## 3. 分类

- 扩量：样本充分、重复转化、ACOS显著低于目标且预算/曝光仍受限
- 健康：接近目标，保持并观察
- 成本偏高：有转化但超过目标，先算理论CPC并分步降价
- 浪费候选：达到点击/目标CPA门槛仍零订单
- 搜索词晋升：重复转化、相关、ACOS健康且尚无独立Exact
- 否定候选：明显不相关，或充分样本下经济性失效；先核实广告组身份
- 结构问题：同一搜索意图跨多个活动抢量、成熟词仍混在探索活动、预算分配与贡献不匹配
- 承接问题：多个高相关词都有点击却普遍不转化，优先检查价格、评论、BuyBox和Listing

## 4. 动作规则

### 默认安全幅度

单次竞价、预算的幅度**上限**和状态动作规则统一以 `calculations.md` 的“安全幅度（唯一出处）”为准，本文件不另定上限。生成任何调整预览前先按该表核对幅度；下面各节给的是建议区间，不得超出该表。

### 竞价

使用 `理论新CPC = 当前CPC × 目标ACOS / 当前ACOS` 作参考，并按置信度限制单次幅度。提价还需确认库存、BuyBox、市场需求和预算空间。

### 预算

连续多日接近日预算且ACOS健康才建议增加10%–20%。ACOS高且预算跑满时先修流量与竞价；只花预算小部分时加预算通常无效。

### 搜索词与否定词

转化搜索词可晋升Exact。是否在原活动否定取决于是否需要流量隔离，不机械同时执行。相关但暂时差的词优先降价/观察；明显不相关且样本充分才优先否定。

### 暂停

暂停是高影响动作。列出活动名称、ASIN、花费、点击、订单、目标线和替代流量来源；确认不会误停共享活动中的其他商品。

## 5. 输出动作清单

逐条给出：对象名称与ID、归属ASIN、当前值、目标值、计算依据、预期效果、风险、置信度和建议观察窗口。再按批次汇总：

- 拟提高/降低竞价
- 拟提高/降低预算
- 拟新增Exact
- 拟新增否定词
- 拟暂停或保持
- 仅观察

默认只是建议。用户明确要求落地后，按操作类型分别生成批量预览。

当用户一开始就明确要求“直接优化并生成审批”时，完成只读诊断后可直接prepare，不再重复询问是否生成预览。必须分别生成竞价、否定词、预算、状态和新Campaign预览；任何正式apply仍由Cherry逐次真人审批。
