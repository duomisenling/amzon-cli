# 经济边界与调整计算

## 利润边界

```text
广告前单件可贡献利润
= 售价 - Amazon佣金 - FBA费用 - 采购成本 - 头程 - 优惠折扣 - 预计退货损失 - 其他变动成本

盈亏平衡 ACOS = 广告前单件可贡献利润 / 售价
目标 CPA = 售价 × 目标 ACOS
可承受 CPC = 预期转化率 × 目标 CPA
```

Amazon费用可用 `fees estimate` 辅助；采购成本、头程和目标利润由运营或ERP提供。缺关键成本时标注经济性未完整验证。

## 未提供利润率或目标ACOS

不要把利润率或目标ACOS当成开始分析的门槛，按以下顺序使用可用依据：

1. 用户给出目标ACOS时，用它计算目标CPA和可承受CPC，并注明这是经营目标，不等于盈亏平衡点。
2. 已有完整成本时，计算盈亏平衡ACOS；若还要求保留目标利润，再据此收紧经济边界。
3. 两者都没有时，仍分析历史花费、点击、订单、CVR、CPC、搜索词浪费、结构覆盖、库存和市场竞争；可用同店同类商品及历史窗口做相对比较，但不得据此宣称盈利。
4. 已有广告可给保留、否定、结构拆分、样本不足观察等不依赖利润率的动作；涉及精确加预算或精确提价时标注“经济性未验证”，并给保守区间或条件式建议。
5. 新品可依据市场CPC和CVR情景输出测试预算、竞价区间及止损观察条件；这些是测试方案，不是利润安全承诺。

报告结尾把利润率、成本或目标ACOS列为“提高经济性判断精度的可选补充”，不要在报告开头阻塞查询。

## 新品假设

新品没有可靠 CVR 时，优先采用公司同类新品历史中位数，其次采用同类成熟商品的保守折扣值；都没有时给 CVR 3%/5%/8% 等多个情景，不给伪精确答案。

市场建议 CPC 是竞争信号，不是必须跟随的出价。市场 CPC 高于可承受 CPC 时，建议改打长尾、降低竞价、改善 Listing或由运营明确接受阶段性亏损。

## 样本门槛

```text
零订单异常点击数 = ln(容许误判概率) / ln(1 - 目标CVR)
```

例如目标 CVR 10%、容许误判10%，约22次点击。样本不足时写“继续观察”。已有转化数据后可计算：

```text
理论新 CPC = 当前实际 CPC × 目标 ACOS / 当前 ACOS
```

新品前3天除明显跑偏或失控外不频繁修改。

## 安全幅度（唯一出处）

以下上限是全流程共用的硬约束。没有公司级策略时按此执行；其他参考文件只引用本节，不另写数字。

| 动作 | 单次幅度上限 |
| --- | --- |
| 关键词竞价（默认/中置信度） | 15% |
| 关键词竞价（证据充分的高置信度） | 25% |
| 日预算增加（连续受限＋转化稳定＋经济边界已验证） | 20% |
| 低置信度 | 不输出精确调整，只观察 |

上限是生成预览的天花板，不是要求每个对象都调到上限。样本不足、共享活动归属不清或经济性无法判断时保持观察。没有目标ACOS、利润或完整成本时不prepare扩预算。暂停/启用属于高影响状态动作，默认只列建议，用户明确允许后才prepare并单独审批。
